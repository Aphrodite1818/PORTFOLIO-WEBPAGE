# Taiwo Ayimora — Backend Engineer Portfolio

A personal portfolio for Taiwo Ayimora, focused on backend engineering, production systems and selected technical projects.

## Preview locally

This website is built with plain HTML, CSS and JavaScript. There are no dependencies or build commands.

Open `index.html` in a browser, or serve the project locally:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Personal photo

The portrait section deliberately falls back to the initials **TA** until a verified personal photograph is supplied. Add your own image as `assets/profile.jpg` to replace the initials automatically. The website does **not** use another person's photo or hotlink a restricted LinkedIn image.

## Deploy on GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`. Once published, the site will be available at:

https://aphrodite1818.github.io/PORTFOLIO-WEBPAGE/

All asset paths are relative, so the page works on GitHub Pages and other static hosts.

## Content and privacy

The site describes Weave Cloud Space and links only to the publicly accessible product at https://weavecloudspace.com. It does not include or link to the private Weave source repository. Contact details and the LinkedIn profile are taken from the applicant's CV.

## Maintain

- Update project and experience copy directly in `index.html`.
- Change colors, spacing and responsiveness in `styles.css`.
- The small set of interactions (navigation, copy email, photo fallback and reveal animations) live in `script.js`.
- `resume.html` is a printable, web-friendly version of the CV, with a Print / Save as PDF button.
